# Blinkit Sales Analysis Dashboard

## Overview
This project is a **Power BI Dashboard** developed to analyze and visualize sales performance, customer insights, and product trends for **Blinkit – India's Last Minute App**. The dashboard provides interactive visualizations and business insights that help understand sales distribution, outlet performance, customer ratings, and product category analysis.

The project was created using **Microsoft Power BI** with data modeling, data cleaning, DAX measures, and interactive visual elements.

---

## Features

- Interactive Power BI dashboard
- Sales performance analysis
- Outlet type and outlet size comparison
- Product category insights
- Customer rating analysis
- Year-wise outlet establishment trends
- KPI cards for quick business overview
- Dynamic filters and slicers for better analysis

---

## Dashboard Insights

The dashboard includes:

### Key Performance Indicators (KPIs)
- Total Sales
- Average Sales
- Number of Items
- Average Rating

### Visualizations
- Sales by Item Type
- Sales by Outlet Size
- Sales by Outlet Location
- Fat Content Analysis
- Outlet Establishment Trend
- Outlet Type Comparison
- Interactive Filtering Options
